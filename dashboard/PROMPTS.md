# A. 과제 1·2: 주식투자 보조 대시보드

`dashboard/invest/` 폴더에서 Claude Code를 열고 아래 프롬프트를 순서대로 입력하면 같은 대시보드(`index.html`)가 만들어집니다.
그래프 1개(S&P 500)로 데이터와 차트 틀을 먼저 확인하고, 지표·차트·시뮬레이터를 붙여 대시보드로 키우는 순서입니다.
필요한 것: Python 3(표준 라이브러리만), 인터넷 연결(FRED 데이터와 Chart.js CDN).

## 2단계. 지표 데이터 늘리기 (`scripts/build_invest.py`)

```
scripts/build_invest.py 를 만들어줘. 표준 라이브러리만 쓰고, FRED 시리즈 7개
SP500, NASDAQCOM, DJIA, VIXCLS, DGS10, DGS2, DEXKOUS 를 같은 주소 형식으로 scripts/.cache/<ID>.csv 에 받아.
값이 비었거나 "." 인 행은 뺀다. invest_data.js 에 window.INVEST_DATA 로 아래를 저장해줘.
- cards: 시리즈마다 마지막 값·날짜와 1일·1개월(30일 전 이전 마지막 값)·연초(전년 12/31 이전 마지막 값) 대비 변화.
  금리(DGS10, DGS2)는 %p 차이, 나머지는 변화율(%)
- signals: S&P 500 종가, 50일·200일 단순이동평균, RSI 14일(Wilder), 고점 대비 하락률, 사상 최고가, VIX,
  10년−2년 금리차, 원/달러와 최근 1년 평균, 마지막 골든·데드크로스(50일선이 200일선을 위·아래로 뚫은 날)
- trend: 최근 2년 일별 [날짜, 종가, 50일선, 200일선] (이동평균은 전체 기간으로 계산)
- crosses: 최근 2년의 골든·데드크로스 [날짜, "golden"|"dead"]
- drawdown: 10년 주간 고점 대비 하락률(%)
- vix, spread: 최근 2년 일별 VIX, 10년−2년 금리차
- monthly: 월말 [YYYY-MM, S&P 500 종가, 같은 날 이전 마지막 원/달러]
실행하고 cards, signals, crosses 를 출력해줘.
```

  추세: 종가가 200일선 위면 "상승 추세"(초록) 아래면 "하락 추세"(빨강), 200일선 대비 %
  모멘텀: RSI 70 이상 "과열"(주의), 30 이하 "과매도"(초록), 그 사이 "중립"(회색)

  환율: 1년 평균보다 3% 넘게 높으면 "달러 비쌈"(주의, "원화로 미국 주식을 사기 부담스러운 때"),

## 5단계. 적립식 시뮬레이터

```
index.html 맨 아래에 "적립식 투자 시뮬레이터 (S&P 500)" 카드를 추가해줘.
- 입력: 매달 투자금(원, 기본 500000), 시작 월(monthly 의 마지막 달 전까지, 기본 5년 전 같은 달), "환율 변화 반영" 체크(기본 켬)
- 계산: 시작 월부터 마지막 달까지 매달 말 종가로 매수. 환율 반영이면 매수 수량 = 금액 / (종가 × 그달 환율),
  평가금 = 수량 × 종가 × 그달 환율. 반영하지 않으면 모든 달에 마지막 달 환율을 쓴다. 배당·수수료·세금 제외라고 적어줘.
- 결과 4개: 투자 기간(개월), 낸 돈, 지금 평가금(만 원), 수익률(상승 초록·하락 빨강)
- 차트: 평가금(파랑, 아래 채움)과 낸 돈(회색 점선), y축 만 원 단위
- "표로 보기 (연말 기준)": 12월과 마지막 달의 낸 돈·평가금·수익률
입력을 바꾸면 바로 다시 계산해줘.
```

## B0. 데이터 준비

```
kr_claims 백업 구글 시트(ID 1nPuY8AKFAs2r9da4xUBV3WMKdLEBZJGpmd3kP7xKNvU)에서

## B1. 집계 스크립트

```
scripts/build_data.py 를 만들어줘. 표준 라이브러리만 쓰고, scripts/.cache/ 의 CSV를 읽어
data.js 에 window.DASHBOARD_DATA 로 아래 집계를 넣어줘.
- kpi: 명세서 수, 진료비 합계(rvd_rpe_tamt_amt), 수진자 수(jid 고유)

- by_type: yid 로 institution 을 붙여 cl_cd 를 얻고, code_table 에서 code_type = '종별코드' 인 행으로 이름을 바꿔
  종별 명세서 수, 건당 평균 진료비, 본인부담률(rvd_slf_brdn_amt 합 / 진료비 합)
- monthly: recu_fr_dd 월별 전체 명세서 수와 main_sick 이 J 로 시작하는 명세서 수
- age_cost: 환자별 2년 진료비 합계를 patient 의 성별(sex_tp_cd)·연령대(2025년 기준, 0-19/20-39/40-59/60-69/70+)로 묶은 평균
```

## B2. 청구 대시보드 (`index.html`)

```
data.js 를 읽는 index.html 대시보드를 만들어줘. Chart.js 4.4.1(cdnjs)을 쓰고 다른 파일은 만들지 마.
독자는 병원 경영기획팀장, 월초 경영회의 전날에 전월 진료비와 환자 구성을 점검하려고 본다. 이 문장을 상단에 넣어줘.
- KPI 카드 3개: 총 명세서 수, 총 진료비(억 원), 수진자 수
- 주상병별 명세서 수 상위 10 가로 막대
- 종별 건당 평균 진료비 세로 막대 (툴팁에 명세서 수, 본인부담률)
- 월별 꺾은선: 전체 vs 호흡기 질환(J) 두 선, 축은 하나만
- 차트마다 "표로 보기" 펼침 표
- 맨 아래 "인사이트:" 한 줄
라이트·다크 모드 색은 CSS 변수로 두고, 모바일 폭에서는 한 열로 쌓아줘.
```

```
